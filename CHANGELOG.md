# Changelog

All notable changes to **FinPulse Enterprise FinTech Platform** are documented in this file.
The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-10-23
### Added
- Complete React 18 single-page treasury management application.
- Real-time treasury liquidity dashboard tracking daily working capital.
- Multi-stage Docker containerization and Docker Compose orchestration.
- Comprehensive end-to-end integration test suite and GitHub Actions workflow.

## [0.4.0] - 2026-09-25
### Added
- B2B Invoice Factoring module with automated credit risk scoring.
- Dynamic advance funding rate calculation (70%-90%) and fee computation.
- Underwriting and disbursement lifecycle state machine.

## [0.3.0] - 2026-08-28
### Added
- Bank Statement MT940 / CSV feed parsing service.
- Smart reconciliation matching engine with fuzzy reference and date tolerance scoring.
- Discrepancy management and audit resolution workflows.

## [0.2.0] - 2026-07-24
### Added
- Multi-currency business wallet framework (USD, EUR, GBP, INR).
- Peer-to-peer wallet transfer pipeline with idempotency key enforcement.
- Escrow and pending balance lock/unlock mechanisms.

## [0.1.0] - 2026-06-26
### Added
- Chart of Accounts taxonomy (Asset, Liability, Equity, Revenue, Expense).
- Double-entry Journal Entry model with strict debit/credit invariant validation.
- Cryptographic SHA-256 block-chaining on journal transactions.
